# CLI reference

## serve

    mockrelay serve
    mockrelay serve --mode replay
    mockrelay serve --latency 200

## record

    mockrelay record

## replay

    mockrelay replay --latency 150

## list

    mockrelay list
    mockrelay list --upstream gh

## stats

    mockrelay stats

## clean

    mockrelay clean --older-than 30 --yes

## init

    mockrelay init

## config

    mockrelay config
